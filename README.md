# 🌍 Air Quality Index (AQI) Analysis & Visualization

## 📌 Project Overview

This project focuses on analyzing **Air Quality Index (AQI) and major air pollutants** to understand pollution patterns, identify highly polluted areas, and generate meaningful insights through data analysis and visualization.

The project follows an **end-to-end data analytics workflow**, starting from raw data cleaning and preprocessing to SQL analysis, Excel analysis, and interactive Power BI dashboards.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall Air Quality Index (AQI) trends.
* Identify cities/locations with poor air quality.
* Analyze major air pollutants such as PM2.5, PM10, NO₂, SO₂ and CO.
* Compare air quality across different cities and locations.
* Understand seasonal and yearly pollution patterns.
* Identify the major pollutants contributing to poor AQI.
* Perform data analysis using SQL.
* Create analytical dashboards using Excel and Power BI.
* Convert raw air-quality data into meaningful business-friendly insights.

# 🧹 Data Cleaning & Preprocessing

The raw dataset was examined and cleaned before performing analysis.

The preprocessing process included:

* Understanding the structure of the dataset.
* Checking the number of rows and columns.
* Identifying missing values.
* Handling missing and inconsistent data.
* Removing duplicate records where required.
* Checking data types.
* Converting columns into appropriate formats.
* Handling inconsistent or incorrect values.
* Preparing the cleaned dataset for further analysis.

The cleaned dataset was then used for **EDA, SQL analysis, Excel and Power BI dashboards**.

# 🗄️ SQL Analysis

SQL was used to perform structured analysis on the cleaned AQI dataset.

The analysis included:

* City-wise AQI analysis
* Average AQI calculation
* Maximum and minimum AQI
* Pollutant-wise analysis
* Ranking cities based on AQI
* Identifying highly polluted locations
* Aggregation using `GROUP BY`
* Filtering using `WHERE`
* Sorting using `ORDER BY`
* Conditional analysis using `CASE`
* Aggregate functions such as `AVG()`, `MAX()`, `MIN()` and `COUNT()`

The SQL analysis helped validate the findings obtained during Python-based analysis.
